# hey, i'm oldskinix 👋

I build mobile apps with Flutter and React Native, and I spend a lot of time thinking about how things should move and respond under your fingertips. There's something satisfying about crafting an interface that feels smooth and intentional, the kind where every transition has a reason. Lately I've been drawn to offline-first architecture — the idea that an app should still feel complete even when the network disappears is a quiet challenge I keep coming back to.

- 🔭 Experimenting with local-first sync patterns in a Flutter side project.
- 🔭 Currently working on mobile UI/UX
- ✨ I prefer boring solutions that work
